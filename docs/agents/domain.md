# 领域文档

本项目采用 single-context 布局：根目录 `GLOSSARY.md` 保存领域术语，`docs/adr/` 保存已确认的架构决策。

## 探索前先读取

- 读取根目录 `GLOSSARY.md`。
- 读取 `docs/adr/` 中与当前工作相关的决策。
- 文件不存在时静默继续；不把缺失视为错误，不提前创建占位内容。由 `/domain-modeling` 在术语或决策实际确定后创建。

## 使用词汇与决策

Issue 标题、设计说明、假设和测试中的领域概念使用 glossary 已确定的词汇。新概念需要在领域讨论中解决，不擅自加入同义名称。

与现有 ADR 冲突时明确指出对应 ADR 和重开讨论的理由，不静默覆盖。

`research/` 与 `architecture/` 里的研究结论和设计提案是讨论输入；未确认的提案不自动成为已接受的架构决策。
