# 将聊天档案的保留与记忆的使用分开管理

为保留相处细节和人工核对的依据，默认保存聊天档案，同时只按需向模型提供允许使用的内容；不通过删除原文来替代上下文管理。使用者要求遗忘后，相关内容必须退出回答、回忆和自动整理，且不能从旧档案、摘要或其他派生材料恢复使用；另提供清除对应原文的操作。这比删除一条记忆记录需要更多来源与失效管理，但能同时满足回看历史和控制大肥鱼记忆的要求。

依据：[产品定义讨论第 4 轮](../design/product-discussion.md)。这是已接受的行为与数据边界，不指定存储引擎，也不代表 DSH 适配及实际清理已验证。
