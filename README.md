# 大肥鱼一站化：研究交付

研究日期：2026-10-25；路线状态更新：2026-10-26（Asia/Tokyo）。目标：先在自己的 Mac 运行，再迁服务器；像普通 QQ 好友一样交流；有稳定人格、人工可管理记忆、真实外部经历和适度主动性。

**当前重点评估：DeepSeek Harness + 统一 `dsh-dafeiyu` 陪伴插件；AstrBot + 完整陪伴模块与管理界面保留为候选。** 用户尚未锁定实施框架。此目录是研究、源码映射和 REA 分析证据，不是已完成的可运行大肥鱼产品。

## 证据怎么读

官方文档说明能力契约；固定提交源码证明实现路径存在；REA 静态结果说明选定发布产物中的观察与推断；QQ 手机上的真实收发与连续试养才能证明目标环境体验。不能把前三类证据写成最后一类。

本轮没有登录 QQ/B站、发送消息、安装或启动 NapCat/AstrBot。研究用 REA 工具在隔离目录中运行，目标发布包未执行；没有修改 Codex MCP 配置。

## 后续实施的第一个完整闭环

QQ 私聊告诉偏好 → 在页面看见记忆 → 人工更正 → 真实读取一条B站内容 → 合适时段主动分享 → 第二天继续话题 → 重启后记忆保留且不重复发送。

先验证这个闭环，再进行一周试养，之后做服务器迁移。每一步都保存输入来源、版本、操作ID与真实结果。
